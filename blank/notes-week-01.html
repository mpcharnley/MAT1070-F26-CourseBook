    Graphs of Equations.

    What is a graph of an equation?
    🔗
    Graphs of equations that look like \(Ax+By = C\) are straight lines. Since it only takes two points to determine a straight line, we can draw these graphs by finding any two points. Two convenient points we can often use are the intercepts.
    🔗

    Definition 3.

    The intercepts of a graph are the places where the graph crosses the axes.
    🔗
     
    🔗
    🔗
    🔗

    Example 4.

    Graph \(3x - 2y = 5\text{.}\)
    🔗
    🔗
    Another way to graph equations of lines is to solve for \(y\) first, then plug points into \(x\text{.}\) In the normal way we will set up these equations in the future, we’ll be looking to analyze how \(y\) changes when we plug in different values of \(x\text{,}\) so solving for \(y\) is usually the way to go.
    🔗

    Example 5.

    Graph \(5x + 3y = 18\text{.}\)
    🔗
    🔗
    When we solve out for \(y\) like this, we are indicating that the value of \(y\) depends on \(x\text{,}\) so that \(y\) is the dependent variable and \(x\) is the independent variable.
    🔗

    Example 6.

    Graph \(y=x^2 - 3x + 1\text{.}\)
